# CivicFlow

**An accessible, user-centred digital service discovery platform.**

CivicFlow is a portfolio project exploring how people can find relevant local services, understand their options and navigate guided digital journeys with greater confidence.

## Project goals

- Apply evidence-based design principles.
- Create and evaluate user journeys and interactive prototypes.
- Build accessible, responsive user interfaces.
- Demonstrate interaction design and inclusive design practices.
- Document design decisions, testing and iterations.
- Implement the experience using modern frontend technologies.

## Planned technology

- Next.js and React
- TypeScript
- Tailwind CSS
- Playwright and accessibility testing tools
- GitHub and Vercel

## UX case study

Research findings, user journeys, design decisions and accessibility documentation will be maintained in the `docs/` directory.

## Project status

Discovery and UX research.

**Note:** CivicFlow is an independent concept project and is not an official government service.
